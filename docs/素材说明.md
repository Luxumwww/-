# 素材说明

## 当前素材

- `assets/reference`：开发时提供的八张猫参考图，保留原始 PNG。
- `assets/generated/transitions-atlas.png`：起身、趴下等过渡。
- `assets/generated/behaviors-v2-atlas.png`：安静坐姿、舔毛、进食、正常脖子咂嘴。
- `assets/generated/walk-v031-atlas.png`：八张完整行走帧。
- `assets/audio`：程序使用的八种 PCM WAV。
- `素材/音频`：原始 MP3，保留以便重新转换。
- `图标.ico`：开发时提供的程序图标。

生成失败的图集、旧步态素材和重复的参考图片文件夹不包含在源码上传包中。早期文档提到的旧素材属于历史实现。

## 声音对应

| 文件 | 状态 |
|---|---|
| growl.wav | 空嚼与连续哈气后的低吼，合成声音 |
| hiss-1.wav | 坐立哈气；炸毛哈气候选之一 |
| hiss-2.wav / hiss-3.wav | 炸毛哈气的其他随机声音 |
| scared.wav | 惊恐弓背（原始文件：老吴.mp3） |
| meow.wav | 回收站空时等饭 |
| satisfied.wav | 吃饱后的舒服低鸣 |
| snore.wav | 开启打呼噜后的睡眠 |

格式为 22050 Hz、单声道、PCM16 WAV。新增音频后先转换再打包：

```powershell
python -m pip install -r tools/requirements.txt
python tools/import_audio.py
powershell -ExecutionPolicy Bypass -File tools/package.ps1
```

只构建和运行现有素材时无需安装 Python。若补充原始图片，可放入 `素材/图片`，转换脚本会同步到 `assets/reference`；也可直接修改后者。

## 补帧原则

参考图是同一只猫的角色设定。保持瘦长身体、长细四肢、小头、黑白花纹和怪异气质。行走使用完整图帧，保留略僵硬的节奏。

生成记录见 [过渡素材](素材生成记录.md)、[0.2 素材](0.2更新与素材.md)、[完整行走帧](0.3.1行走修复.md)。记录中的本地验证产物未包含在仓库，公开预览位于 `docs/images`。
