# MVP 验证记录

日期：2026-09-30；环境：本机 Windows、.NET SDK 10.0.401、Windows Desktop Runtime 10.0.12。

## 构建与行为测试

Release 构建：0 警告、0 错误。无额外 NuGet 依赖。

12 项自动化测试通过：

1. 完整 sleep / wake / wander / observe / approach / chew / hiss / recover / lie down / rag / curl / sleep 循环。
2. 没有新鼠标活动时保持睡眠。
3. 点击打断起身和休息、连点升级、连点计时过期、可调整阈值。
4. 静止鼠标不会让低吼持续无限循环。
5. 鼠标移远重新追逐，过远放弃。
6. 鼠标处于头部与身体之间时不反复左右翻转。
7. 猫主动靠近鼠标不误判为鼠标突然袭击。
8. 负坐标显示器及透明边距的边界约束。
9. 拖动阈值、拖动偏移和丢失鼠标捕获后的清理。
10. 所有姿态载入、alpha 透明、显示范围、左右镜像。
11. chew 下颌动画确实改变可见像素。
12. WAV 解码、长度、非静音、幅度有效性。

运行：`dotnet run --project tests/Hajimi.Tests -c Release`。
