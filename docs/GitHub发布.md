# GitHub 发布步骤

## 源码仓库

把源码上传包解压后的内容上传到 GitHub 仓库根目录。根目录应直接看到 `README.md`、`src`、`tests`、`assets` 和 `图标.ico`。

源码包包含可构建所需素材、原始 MP3、脚本、预览和说明。没有编译缓存、旧版本 EXE、第三方工具缓存或本机验证截图。不要把整个开发工作区上传。

## Releases

创建版本标签 `v0.4.0`，标题可用“哈基米桌宠 v0.4.0”。上传发布附件：

- `哈基米.exe`：单文件运行版。
- `SHA256SUMS.txt`：EXE 校验值。

发布说明可使用整理目录中提供的 `release-notes.md`。源码 ZIP 可选作为附加下载；GitHub 也会根据标签提供源码下载。

EXE 放在 Releases，源码仓库中保持忽略。后续发布先运行测试与打包，更新 `CHANGELOG.md`、项目版本与发布说明，再上传新的 EXE 和校验值。

## 许可证

仓库中已选择 MIT 许可证，发布时保留根目录的 `LICENSE`。素材来源记录见 [素材说明](素材说明.md)。
