# 0.4 打包与菜单

## 使用

双击根目录的 **哈基米.exe**。Windows x64 单文件运行版内含 .NET 运行时、全部角色图片与音频，文件可单独复制使用。运行时会自动把必要的原生运行库解压到系统临时缓存，偏好设置继续保存在 `%LOCALAPPDATA%/Hajimi/settings.json`。

根目录 `图标.ico` 同时用于 EXE 文件图标、托盘、猫窗口和设置窗口。项目名与已有偏好设置目录保留，因此更新后原来的大小、睡眠、声音等设置继续使用。

## 右键菜单

主菜单从长列表缩为 10 行：当前状态、六个分类、分隔线、全部设置、退出。功能未减少。

- **动作**：叫醒、睡觉、烂抹布，普通性格时显示站着/坐着蔑视。
- **性格**：好猫模式、叼走鼠标、挑衅次数；嘎蛋后显示装回铃铛。
- **吃饭**：自动进食、去找饭、饥饿倒计时、回收站空满与位置、这里设为饭盆、寻找回收站。
- **声音**：静音、睡觉打呼噜、音量。
- **显示**：置顶、大小滑块、移回当前屏幕、开机自启。
- **睡眠**：20/35/60/120 秒、随机、自定义。

点击三级大小滑块菜单以外的位置仍会收起整套菜单。菜单打开期间继续暂停猫的行为和声音。

## 开机自启动

右键 **显示 → 开机自启**，或者全部设置中的开机自启动复选框。首次使用默认关闭。仅用户明确勾选后，写入当前用户的注册表启动项：

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
Hajimi.DesktopPet = "EXE 的完整路径"
```

取消勾选仅删除 `Hajimi.DesktopPet` 这一项，其他启动项保留。路径始终加引号，支持中文和空格。登录用户后启动，无需管理员权限。开关状态读取真实注册表值，普通设置保存不会重新创建被移除的启动项。

如果已启用自启后移动 EXE，手动运行新位置的 EXE 一次会刷新路径；关闭时不会自动启用。直接从 `dotnet` 开发宿主运行时不允许启用自启。自启设置失败会提示，复选框恢复实际状态。

## 打包设计

- 发布配置：`src/Hajimi/Properties/PublishProfiles/Standalone.pubxml`。
- Windows x64、self-contained、单文件、压缩内置运行库，不裁剪 WinForms。
- 图片、角色配置和 WAV 作为嵌入资源读取；没有外部 `assets` 文件夹也能加载。开发目录的外部素材仍可覆盖内置素材。
- 运行库由 .NET 单文件宿主加载，必要的原生库自动提取到缓存。
- 未采用的两张行走图不打包。
- 重复打包：先退出根目录 EXE，再运行 `powershell -ExecutionPolicy Bypass -File tools/package.ps1`。

## 验证

48 项自动测试通过，新增检查覆盖：完全没有外部素材时的全部姿态和八种声音、内置 ICO 与用户原文件逐字节一致、自启默认关闭与路径刷新、关闭移除、中文空格路径加引号、拒绝异常路径与开发宿主。自启测试使用内存存储，不替用户开启真实开机设置。

单文件验证把 EXE 单独放入 `artifacts/standalone-isolated`，该目录没有 DLL、图片、音频或配置文件；将运行库缓存指定到工作区，使用该 EXE 的 `--smoke-test` 执行完整窗口与交互循环。演练记录和菜单截图保存在 `artifacts/standalone-smoke`。

- EXE 为 68,080,430 字节，约 64.9 MiB；文件版本为 0.4.0.0。内置运行时为 .NET / WindowsDesktop 10.0.12。
- 原生 EXE 图标资源也与 ICO 的图像数据逐字节一致，记录为 `ExecutableWin32IconEqualsSuppliedICO=True`。
- 演练结束 `finished=True; final=Sleep`，音频可用，菜单为 172×208 像素；三级滑块内部点击保留菜单，外部点击收起并恢复声音，反复打开菜单后 GDI 数不增长。
- 隔离演练未找到桌面图标窗口，饭盆阶段使用模拟位置和空满变化；不把这次演练当作真实桌面回收站定位的确认。
- 自启动测试没有写入真实启动项。正常启动新版后只读确认 `StartupEnabled=False`，保留默认关闭。
- 旧版正常退出，根目录新版已启动；启动脚本优先运行根目录 EXE，旧发布目录保留。
