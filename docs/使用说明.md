# 使用说明

双击根目录的 **哈基米.exe**，也可使用 **启动哈基米.cmd**。这是 Windows x64 单文件运行版，图片、音频、图标和 .NET 运行环境都已包含，只复制这个 EXE 即可使用。右键猫或任务栏托盘图标打开菜单；双击托盘图标叫醒它。

## 菜单与开机自启

主菜单收纳为 **动作、性格、吃饭、声音、显示、睡眠**，保留全部原有选项。

| 分类 | 选项 |
|---|---|
| 动作 | 叫醒、睡觉、烂抹布、站着/坐着蔑视 |
| 性格 | 好猫模式、叼走鼠标、挑衅次数、嘎蛋后装回铃铛 |
| 吃饭 | 自动进食、去找饭、饭盆状态、这里设为饭盆、寻找回收站 |
| 声音 | 静音、睡觉打呼噜、音量 |
| 显示 | 置顶、大小滑块、移回当前屏幕、开机自启 |
| 睡眠 | 固定秒数、随机、自定义 |

**显示 → 开机自启** 默认关闭。开启后在当前 Windows 用户登录时启动；取消勾选即移除本程序的启动项。全部设置中也有相同开关。使用当前 EXE 的完整路径，无需管理员权限。开启后请保留 EXE 的位置；移动后手动运行一次，会更新已启用的自启路径。其他偏好设置的保存不会开启自启。

EXE、托盘和设置窗口均使用根目录的 `图标.ico`。打包说明与验证见 `docs/0.4打包与菜单.md`。

## 这版怎么用

- **大小**：右键“显示 → 大小”里直接拖滑块；范围 40%～160%。
- **睡眠**：右键“睡眠”，可选预设、随机或自定义。全部设置里可输入固定秒数、随机最短与最长秒数。到时间直接使用待机睡姿；烂抹布仅用于手动摆烂和嘎蛋。
- **置顶**：右键“显示 → 置顶”开关。
- **好猫模式**：自己溜达、坐着、舔毛、找饭，不追鼠标、不受点击挑衅。猫上仍可右键打开完整菜单、左键拖动；周围透明区域允许鼠标穿透。也可从托盘打开菜单。
- **右键菜单**：点击菜单或子菜单以外的位置会收起，并恢复猫的活动和声音。
- **睡觉打呼噜**：右键“声音 → 睡觉打呼噜”开关。默认关闭，音量与静音也在声音菜单及全部设置中。
- 普通模式左键点猫产生反应，按住左键移动超过 7 像素可拖动。可拖到其他显示器。

## 叼走鼠标与嘎蛋

先右键开启 **性格 → 叼走鼠标**，默认关闭。未嘎蛋且好猫模式关闭时，连续挑衅达到阈值，猫会在连续哈气后的咂嘴阶段叼走真实鼠标，让鼠标跟着嘴在所在屏幕上跑。每次最多 8 秒。

- **空格**：释放鼠标、嘎蛋，猫进入烂抹布状态。
- **Esc**：直接释放鼠标，保持原本性格。
- 关闭抢鼠标、打开设置、切换好猫/嘎蛋状态或退出程序，也会释放鼠标。另有独立超时释放。
- 嘎蛋后不哈气、不蔑视、不抢鼠标；会安静坐着、自己舔毛、睡觉、摆烂和吃饭。
- 嘎蛋后右键“性格”中出现 **装回铃铛**，恢复原来的性格。全部设置里也能直接切换嘎蛋状态。

空格和 Esc 只在叼鼠标期间被桌宠处理。

## 点击规则

| 点击前 | 点击后的反应 |
|---|---|
| 睡觉 / 起身 | 随机：惊恐弓背、站立蔑视、坐立蔑视 |
| 坐立蔑视 / 坐立哈气 | 坐立哈气 |
| 站立蔑视 | 随机：炸毛哈气、惊恐弓背 |
| 惊恐弓背 | 炸毛哈气 |
| 鼠标附近的空嚼 / 其他活动 | 炸毛哈气 |
| 嘎蛋状态 | 安静坐着或自己舔毛 |
| 好猫模式 | 不挑衅；左键拖动、右键菜单仍可用 |

单次哈气直接恢复。短时间内多次**真正哈气**达到阈值才进入“气得咂嘴”，使用正常脖子；原来的鼠标附近空嚼继续用伸脖子姿态，嘴部朝鼠标方向上下转动。阈值可在右键菜单和全部设置中调整。

## 回收站当饭盆

默认约 3 分钟后会饿并自动去找饭，包括从睡觉中醒来。右键 **吃饭 → 自动进食** 可开关；在“全部设置 → 行为与睡眠”调整“吃饱后多久再饿”。“吃饭”菜单显示距离下一次饿还有多久；菜单、设置和拖动期间倒计时暂停。改变饥饿间隔立即按已过去的时间生效，睡觉不会重新计时。

关闭自动进食仍可右键 **吃饭 → 去找饭**，手动等饭、吃饭和吃饱后的低鸣照常进行。

程序自动寻找桌面回收站图标，并只读查询内容数量。空时在附近走两步、停下来喵叫，等到检测到内容才进食；吃完播放舒服的低鸣。**进食是动画，里面的文件保留。** 喵叫间隔约 6 秒。

右键 **吃饭 → 寻找回收站** 会清除手动饭盆位置并立即扫描；完成时提示是否找到，菜单显示定位坐标。这个命令负责寻找位置，想立即吃饭可接着点“去找饭”。支持系统语言和用户重命名后的回收站显示名称。

如果桌面图标隐藏或回收站未启用，提示会给出处理方法。也可把猫拖到回收站附近，右键“吃饭 → 这里设为饭盆”。暂时找不到图标时保留饥饿，重新找到后自行过去。

## 音频

原始 MP3 保存在 `素材/音频`。程序使用 `assets/audio` 中转换好的单声道 22050 Hz、PCM16 WAV：

| 场景 | 提供的音频 | 运行素材 |
|---|---|---|
| 睡觉（开关开启时） | cat-purr-3d-surround-sound.mp3 | snore.wav |
| 回收站空、等饭 | 喵喵叫.mp3 | meow.wav |
| 吃饱 | soothing-cat-purr.mp3 | satisfied.wav |
| 坐立哈气 | 哈气1.mp3 | hiss-1.wav |
| 炸毛哈气 | 哈气1～3.mp3 随机，避免连续重复 | hiss-1～3.wav |
| 惊恐弓背 | 老吴.mp3 | scared.wav |
| 鼠标附近空嚼 / 连续哈气后咂嘴 | 第一版合成低吼 | growl.wav |

嘴部根据播放中的音频幅度开合；静音时仍能看到动作。音量为本程序独立音量，不修改系统音量。

## 素材与动画

八张参考图保存在 `assets/reference`。三张新图已用于惊恐弓背、坐立蔑视、坐立哈气。新增安静坐姿、舔毛、进食、正常脖子咂嘴素材在 `assets/generated/behaviors-v2-atlas.png`。

0.3 的腿部裁切和骨骼变形会产生腿根切口，已在 0.3.1 删除。现在使用 `assets/generated/walk-v031-atlas.png` 的八张完整行走图，直接播放整只猫，不拆开四肢。全部帧使用同样大小的画布，只整体平移对齐脚底；角色大小和透明边距不会逐帧变化。行走帧随实际移动距离前进，停下来也停止换帧，保留略僵硬的简化步态。补图、提示词与放大检查记录见 `docs/0.3.1行走修复.md`。

## 开发与验证

开发需要 .NET 10 SDK。运行根目录单文件 EXE 无需另外安装 .NET。重新打包前先退出正在运行的根目录 EXE：

```powershell
dotnet run --project tests/Hajimi.Tests -c Release
powershell -ExecutionPolicy Bypass -File tools/package.ps1
```

打包配置位于 `src/Hajimi/Properties/PublishProfiles/Standalone.pubxml`，产物先输出到 `release/Hajimi-0.4-single/Hajimi.exe`，再复制到根目录 `哈基米.exe`。更换 MP3 后，可运行 `python tools/import_audio.py` 再重新打包。转换脚本需要 imageio-ffmpeg，仅用于开发时转换。

```powershell
dotnet src/Hajimi/bin/Release/net10.0-windows/Hajimi.dll --render-preview artifacts/preview
dotnet src/Hajimi/bin/Release/net10.0-windows/Hajimi.dll --smoke-test artifacts/smoke
```

窗口演练静音运行，并用模拟方式验证叼鼠标、空格嘎蛋和喂饭，不改变真实回收站内容、不保存用户设置。真实鼠标约束与恢复另有原生探测。交互验证见 `docs/0.3更新与验证.md`，当前行走修复见 `docs/0.3.1行走修复.md`。

模块继续分为 `Behavior`、`Animation`、`Interaction`、`Audio`、`Assets`、`Platform`。设置保存于 `%LOCALAPPDATA%/Hajimi/settings.json`；启动失败详情写入同目录的 `error.log`。

逐像素窗口使用 [UpdateLayeredWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-updatelayeredwindow)，叼鼠标使用 [ClipCursor](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-clipcursor)，回收站空满使用 [SHQueryRecycleBin](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shqueryrecyclebinw)。
