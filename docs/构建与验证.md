# 构建与验证

## 开发环境

Windows x64 和 .NET 10 SDK。单文件运行版已包含运行环境，使用者无需 SDK。

在仓库根目录执行：

```powershell
dotnet run --project tests/Hajimi.Tests -c Release
powershell -ExecutionPolicy Bypass -File tools/package.ps1
```

或者一次完成：

```powershell
powershell -ExecutionPolicy Bypass -File tools/build.ps1
```

发布配置位于 `src/Hajimi/Properties/PublishProfiles/Standalone.pubxml`。中间产物为 `release/Hajimi-0.4-single/Hajimi.exe`，用户入口为根目录 `哈基米.exe`。二者均不提交到源码仓库，EXE 应作为 Releases 附件上传。

## 预览与窗口演练

```powershell
dotnet build src/Hajimi/Hajimi.csproj -c Release
dotnet src/Hajimi/bin/Release/net10.0-windows/Hajimi.dll --render-preview artifacts/preview
dotnet src/Hajimi/bin/Release/net10.0-windows/Hajimi.dll --smoke-test artifacts/smoke
```

演练为静音与模拟鼠标捕获，不修改真实回收站内容，不保存用户设置。截图与日志输出到指定文件夹。

生成 GIF 需要可选 Python 依赖：

```powershell
python -m pip install -r tools/requirements.txt
python tools/preview_gifs.py artifacts/preview
```

## v0.4.0 验证范围

48 项测试覆盖状态循环、好猫模式、点击规则、睡眠、自动/手动进食、音频选择、完整行走帧、嘴部定位、鼠标捕获的模拟释放与自启注册逻辑。自启注册测试使用内存存储，不替使用者开启真实开机设置。

单文件窗口演练在没有外部素材文件夹的目录中完成醒来、走动、追鼠标、空嚼、哈气、恢复、等饭、吃饭、低鸣和睡觉。菜单在内部点击时保留，外部点击后收起；反复打开未观察到 GDI 增长。

早期验证记录保留供阅读；旧步态与第一阶段的行为说明不代表当前实现。
